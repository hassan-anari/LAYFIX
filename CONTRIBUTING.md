# Contributing to LAYFIX

LAYFIX has a Phase 1 development preview; interactive Windows validation remains an owner gate. All contribution work must follow [AGENTS.md](AGENTS.md), [Development Workflow](docs/DEVELOPMENT_WORKFLOW.md), and [Security and Privacy](docs/SECURITY_PRIVACY.md).

- Use an issue/task with explicit phase scope and acceptance criteria.
- Submit changes in a Draft PR; do not push to main, merge, tag or release without owner approval.
- Write code/comments/docs/PR descriptions in English. User-facing English/Persian strings require correct locale/RTL handling.
- Include tests and source/license attribution for dependencies or borrowed material.
- Never post keystroke recordings, typed content, clipboard dumps, credentials or sensitive traces.
- Report run results accurately, especially interactive Windows tests not performed in CI.

An explicit repository license and external contribution terms are pending owner selection; do not presume an open-source grant merely from visibility.
